# Neuroconsole
Interactive console with command-line input. Displays basic neuronal physiology and the firing
of action potentials.

In the action potential simulation, it generates a random membrane voltage (between -70mV and -40 mV)
and checks whether the voltage exceeds the threshold (-55 mv).

# Commands
* parts: Displays the basic parts of a neuron
* shoot: To apply the voltage
* leave: To exit the Neuroconsole

# How to use
* Download `miconsola.py`
* To run this code, you need to have `Python` installed on your computer.
* Run the script in terminal
> **Tip** If you have both (Rstudio and Python), you can open this proyect in the terminal and run:
> python miconsola.py
